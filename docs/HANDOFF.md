# Grey Invasion Pinball — handoff (2026-10-08)

Second iPhone pinball table, after the Orbit Pinball proof of concept. Theme: defend a farm town from classic grey aliens, played for laughs (goofy tone); three waves of ships (Scout Saucers → Fighter Squadron → Abductors) build to a Mothership multiball finale.

- Plan doc: "Grey Invasion Pinball — Table Plan" (https://claude.ai/code/artifact/7fa23ccc-9724-4c9b-8ee4-9464254a281d) — overview, carry-overs, layout diagram, waves/modes, scoring, cameras/HUD/settings, art/lights/sound, 11 milestones, decisions.
- Build with the spritekit-pinball skill (/spritekit-pinball): proven flipper physics, gates, contacts, rules, pause, sound pipeline, shipping steps, plus guidelines for scale, cameras, ramp layers, lamps and modes.
- orbit-pinball-reference/ in this Project = the finished Orbit Pinball source, for reuse (Flipper, Effects, Sound, gate and pause patterns, menus, credits).
- gi-src/ in this Project = the current Grey Invasion source (mirror of the Mac project), plus gi-src/tools/render_m1.py (matplotlib geometry render of the grey box).

## Multiball engine (milestone 5 round 1) — Ball.swift
- `Ball` (an SKNode with the physics body + a child circle visual) holds every per-ball value that used to be scene-wide: layer (floor / rampUp / rampDown), activeRamp, previousPosition (ramp switch crossings), heldIn / releaseAt / scoopIgnoreUntil (scoops), diverterSolid. `BallLayer` moved there. Ball.setLayer sets the collision mask, z and ramp scale.
- TableScene keeps `balls: [Ball]` and `servedBall` (the ball last put on the plunger; the launch gate follows it). Ramps, scoops, kickback, speed clamp and contacts loop over balls; a scoop holds at most one ball; the kickback saves one ball then goes out.
- Drain: every ball below the table is removed; the player only loses a ball (game.ballDrained) when the LAST ball in play is gone.
- Camera + debug tag follow `focusBall` = the lowest ball in play (the one about to need the flippers). Tag shows "· N balls" when more than one.
- Orbit diverter: now a permanent PhysicsCategory.diverter (1 << 10) edge; each floor ball adds it to its own collision mask while moving right, so it's one-way per ball (was a table-wide toggle). Drawn bright while solid for any ball.
